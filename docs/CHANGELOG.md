# Changelog

## 2026-09-15 (вторая) · Хранилища: единый блок, per-provider ключи, стабильность

### Добавлено
- Единый блок «Провайдер Хранилища»: карточки Google / Yandex / Cloudflare R2 / Selectel / Custom со статусом и переключением активного одним кликом (у каждого провайдера — свои сохранённые ключи).
- Сервисные действия отдельным сворачиваемым разделом: починка источников Drive, сброс конфигурации хранилища (сам action reset_config теперь существует на сервере).
- Мастер подключения R2 всегда доступен над карточками.

### Исправлено
- Удаление слова/фразы в редакторе транскрипта больше не задевает соседние слова (критерий «центр слова в диапазоне удаления»); восстановление стало точным.
- Доступ к микрофону запрашивается системой сразу при первом использовании голосовых функций.
- Поле Secret Access Key явно показывает сохранённое состояние и объясняет смену ключей.
- Настройки хранилища больше не возвращают 500 при сбоях БД — автоматический fallback на прежнюю схему.
- Блок «Хранилища» больше не спрятан внутри справочной модалки.

## 2026-09-15 · UX-полировка: PWA, микрофон, восстановление состояния

### Исправлено
- Шапка плеера больше не уезжает под «динамический остров» на iPhone: safe-area отступы работают и в Safari, и в PWA; базовые отступы шапки сохранены (в т.ч. на десктопе).
- Восстановлены сломанные обработчики настроек хранилища (страница настроек работала не полностью).
- Сброс конфига хранилища очищает оба поля ключей — повторный ввод с нуля без тупика с маской.
- Баннер «хранилище не настроено» исчезает сразу после успешного подключения/проверки, не дожидаясь перезагрузки.
- Экран критической ошибки плеера получил кнопку «← Назад» (возврат без потери страницы).

### Улучшено
- При отказе в доступе к микрофону показывается понятная инструкция для iOS (Настройки → Safari / Anotee), PWA и ПК (замок у адреса сайта) — на русском и английском.

## 2026-09-14 · BYOS: управление хранилищами и честные ошибки

### Добавлено
- Мастер подключения Cloudflare R2 за 3 шага (токен -> ключи -> автопроверка и CORS).
- Управление хранилищами: выбор активного и отключение/включение (сохраняется в аккаунте, действует на все устройства).
- Журнал действий с хранилищами на сервере (storage_audit).

### Исправлено
- Комментарии/маркеры больше не теряются при быстрых действиях: конфликт версий на сервере разрешается retry-with-merge вместо отказа 409 (ISS-017).
- Устройства пользователей получали устаревшую сборку (манифест BTVOE7AL не менялся с 09.09): диагностика по манифест-хешу в консоли — ISS-022, лечение: очистка данных сайта для dev.anotee.com + проверка статуса деплоя Vercel.
- Пустое поле секрета при отсутствии конфига (тупик «пересохраните ключ»).
- В BYOS видно, к какому аккаунту привязано хранилище.
- Ошибка 400 содержит префикс user_id для диагностики «тот ли аккаунт».
- Мастер больше не показывает ложный успех CORS, если токен не имеет права на CORS (подсказка с двумя путями решения).
- Загруженное видео больше не «слетает» при сбое синхронизации: 3 автоматических повтора + понятное сообщение.

### Заметки для пользователей
- Нужен именно R2 API Token (раздел R2 -> API Tokens) с правом Object Read & Write; общий Account API Token не подходит.
- Secret показывается один раз — сохраните его в менеджер паролей.

### Откат
- git revert последних коммитов BYOS (без миграций БД; новые таблицы storage_prefs/storage_audit безопасны и не мешают старым конфигам).
