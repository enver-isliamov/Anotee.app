# Changelog

## 2026-09-22 (ночь) · Навигация, плеер и компактная шапка

### Добавлено
- **Гость** получает все публичные разделы: нижнее меню «Возможности · Как это работает · Демо · Цены · О нас», а Roadmap, Оферта и Политика — из футера (ссылки «Разделы» доступны с любой страницы).
- **Авторизованный**: рабочее меню под ревью — «Проекты · Возможности · Настройки · Профиль» (кнопка «Тарифы» убрана: тариф живёт в «Профиле»).
- Диагностика автосоздания R2-ключа: сервер заранее сообщает, есть ли у токена право «Account API Tokens: Edit» (`canCreateKeys`), а при отказе возвращает понятную причину, код Cloudflare (напр. 9109) и ссылку на ручное создание ключа.

### Изменено
- **«Профиль» и «Настройки» — разные страницы** (/profile и /settings), а не вкладки на одной: переключатель убран, вместо него кросс-ссылка; добавлен маршрут /settings при прямом заходе.
- **Поле ввода комментария в плеере перенесено под таймлайн** (на десктопе панель остаётся справа) — при открытой клавиатуре на телефоне поле остаётся рядом с видео и таймлайном.
- **Шапка компактнее**: настройки, название аккаунта/организации и аватар объединены в один блок; убран дублирующий второй аватар.
- Плавающая панель управления плеера больше не «садится» на шапку (клампинг позиции с учётом высоты шапки).
- «Сохранить и активировать» в хранилище не отправляет конфиг без Access Key ID — вместо непонятного `Missing required fields` показывается подсказка.

### Проверено
- `npx tsc --noEmit` → 0; `npm run verify` → 0 (unit 61/61, инварианты 5/5); `npx playwright test` → **53 passed**; `npm run build` → 0 (precache 22 файла, кэш `anotee-v2bf3a04556`).
- Измерено на мобильном (390×844): поле ввода `top=418` при `bottom` таймлайна `374` (поле строго под таймлайном), позиция `static` (не прибито к низу), фокус не уводит поле за пределы вьюпорта.
## 2026-09-21 (пятая) · Навигация гостя и разделение «Профиль» / «Настройки»

### Добавлено
- Нижнее меню для **неавторизованных**: только доступные им разделы — Возможности · Как это работает · Цены · О нас (без «Проекты», «Настройки», «Профиль»).
- e2e-покрытие гостевой навигации (tests/e2e/guest-nav.spec.ts): 4 публичных раздела, переходы, отсутствие горизонтального overflow; прямой заход гостя на /profile и /settings не показывает личный кабинет.

### Изменено
- «Профиль» и «Настройки» — два разных экрана, а не прокрутка по якорям: в «Профиле» карточка аккаунта (данные, тариф, организация, выход) и подписка; в «Настройках» — хранилище, подключения и сервисные действия (восстановление данных).
- Переключатель разделов больше не скроллит к якорю: разделы независимы, при переключении страница поднимается вверх.
- Заголовок и подпись страницы зависят от раздела.

### Исправлено
- Пункт нижнего меню «Профиль» был подписан как «Настройки» (дубль метки) — теперь корректные подписи и локали ru/en (ключи nav.profile, nav.how, nav.about).
- Тесты хранилища (wizard-flow, edge-cases, mobile-shell, screenshots) приведены к новому потоку: раздел «Настройки» открывается явно.

### Проверено
- npx tsc --noEmit → 0; npm run verify → 0 (unit 61/61, инварианты 5/5).
- npx playwright test → 48 passed (включая guest-nav и разделение разделов).


## 2026-09-21 (четвёртая) · Офлайн-режим и разделы настроек

### Добавлено
- Офлайн-режим (Service Worker): precache оболочки (22 файла), версионирование кэша по хешу сборки, удаление старых кэшей, офлайн-экран «Нет сети», баннер «Доступно обновление → Обновить», индикатор состояния сети.
- Стратегии кэширования: навигация — network-first с фолбэком на кэш, статика — cache-first, /api — только сеть (офлайн отдаёт понятный 503), внешние домены не кэшируются.
- Разделение страницы: «Профиль» (личные данные, организация, тариф, выход) и «Настройки» (хранилище, сервисные действия) с сегментированным переключателем и маршрутом /settings.
- Нижнее меню: Проекты · Тарифы · Настройки · Профиль (пункт «Хранилище» заменён разделом «Настройки» со прокруткой к блоку хранилища).

## 2026-09-20 (вторая) · Мастер Cloudflare «в один клик», PWA-навигация, IndexedDB, CI

### Добавлено

### Исправлено

- CI на GitHub Actions: workflow был невалидным и не запускался — переписан (typecheck/lint/unit/audit/build + e2e).

## 2026-09-14 · BYOS: управление хранилищами и честные ошибки

### Добавлено
- Мастер подключения Cloudflare R2 за 3 шага (токен -> ключи -> автопроверка и CORS).
- Управление хранилищами: выбор активного и отключение/включение (сохраняется в аккаунте, действует на все устройства).
- Журнал действий с хранилищами на сервере (storage_audit).

### Исправлено
- Комментарии/маркеры больше не теряются при быстрых действиях: конфликт версий на сервере разрешается retry-with-merge вместо отказа 409 (ISS-017).
- Устройства пользователей получали устаревшую сборку (манифест BTVOE7AL не менялся с 09.09): диагностика по манифест-хешу в консоли — ISS-022, лечение: очистка данных сайта для dev.anotee.com + проверка статуса деплоя Vercel.
- Пустое поле секрета при отсутствии конфига (тупик «пересохраните ключ»).
- В BYOS видно, к какому аккаунту привязано хранилище.
- Ошибка 400 содержит префикс user_id для диагностики «тот ли аккаунт».
- Мастер больше не показывает ложный успех CORS, если токен не имеет права на CORS (подсказка с двумя путями решения).
- Загруженное видео больше не «слетает» при сбое синхронизации: 3 автоматических повтора + понятное сообщение.

### Заметки для пользователей
- Нужен именно R2 API Token (раздел R2 -> API Tokens) с правом Object Read & Write; общий Account API Token не подходит.
- Secret показывается один раз — сохраните его в менеджер паролей.

### Откат
- git revert последних коммитов BYOS (без миграций БД; новые таблицы storage_prefs/storage_audit безопасны и не мешают старым конфигам).
